SOBRE O PORTAL

Informação organizada para quem vive a estrada.

Este projeto apresenta uma interface independente para consulta das rodovias paulistas. Os códigos e os principais pontos de passagem usados no catálogo foram estruturados a partir da relação de rodovias estaduais disponibilizada pelo DER-SP.

Este site não representa oficialmente o DER-SP, ARTESP ou qualquer concessionária. Informações de trânsito, obras e bloqueios devem ser confirmadas nos canais oficiais.
